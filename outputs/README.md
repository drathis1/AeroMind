# AeroMind — sample outputs

This folder satisfies the *"Outputs"* item of the course packet
(`Required Project Package` → *"exported artifacts, sample runs, or
representative outputs generated by the project"*). Only
`sample_runs/` is populated — the other two recommended subfolders
(`demo_outputs/`, `exported_artifacts/`) are intentionally omitted
so the repository does not ship empty directories. Add them back if
and when real exports exist.

Everything here was produced by a real run of AeroMind on the
submission checkout (see `eval/version_notes.md`). Files are
deterministic and can be regenerated with the script in the parent
`README.md`.

## Folder contents

### `sample_runs/`

Captured HTTP responses from the live FastAPI server
(`uvicorn aeromind.api.main:app --port 8765`) and direct orchestrator
invocations. Each file pairs the request (endpoint, body) with the
actual response the system returned.

| File | What it captures |
|---|---|
| `00_health.json` | `GET /health` liveness probe |
| `01_demo_orders_list.json` | `GET /api/demo/orders` — three seeded orders |
| `02_demo_workflow_trigger.json` | `POST /api/demo/orders/{id}/workflow/trigger` — starts the demo pipeline on `ORD-449836` |
| `03_demo_workflow_run_all.json` | `POST /api/demo/orders/{id}/workflow/run-all` — runs CargoComply → ClearPath → LoadIQ to completion |
| `04_demo_order_detail_after_run.json` | `GET /api/demo/orders/{id}` — full order detail (timeline, shared state, agent logs, governance) after a complete run |
| `05_orchestrator_new_booking.json` | `NEW_BOOKING` event driven through `run_orchestration` directly — `status=CLOSED_CLEAN`, LoadIQ + CargoComply both complete, `autonomous_commits=1` |
| `06_orchestrator_weather_two_phase.json` | `WEATHER_ALERT` event driven through `run_orchestration` — shows the two-phase handoff (ClearPath first, then LoadIQ + CargoComply in parallel) — this is the core architectural differentiator |
| `07_tool_try_cargocomply_booking_denied.json` | Live `ToolRegistry.enforce_allowlist` denial: CargoComply tries to call `booking_write` and is refused with `CARGOCOMPLY_BOOKING_FORBIDDEN` |

## How to regenerate

```bash
# From the repo root
pip install -e ".[dev]"
PYTHONPATH=. uvicorn aeromind.api.main:app --host 127.0.0.1 --port 8765 &

# Demo pipeline samples (00–04)
curl -s http://127.0.0.1:8765/health > outputs/sample_runs/00_health.json
curl -s http://127.0.0.1:8765/api/demo/orders > outputs/sample_runs/01_demo_orders_list.json
# ... see the file headers for the curl commands used

# Orchestrator samples (05–06) — no DB required
PYTHONPATH=. python3 -c "see 05/06 capture scripts in AI_USAGE.md or commit history"

# Allowlist denial (07) — no DB, no network
PYTHONPATH=. python3 -c "see 07 capture script in AI_USAGE.md"
```
