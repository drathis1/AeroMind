# Individual contribution reflections

Each team member writes a short (≈ 300–500 word) markdown file in this
folder before submitting:

- `dhiksha.md`
- `sai.md`
- `smridhi.md`
- `tina.md`

Suggested structure (matches course packet expectations):

1. **What I owned** (specific files, modules, or deliverables).
2. **What I learned** (design call, evaluation insight, failure iteration).
3. **What I would change next time** (one concrete thing).

Link these files from `../../../docs/final_report.md` §Appendix A if you
want them visible from the main report.
