# Phase 3 submission checklist

From course packet §"Final submission checklist". Tick each box before
submitting on Canvas.

- [ ] README with run and navigation instructions — `README.md`
- [ ] Final report PDF — `docs/final_report.pdf` (export
      `docs/final_report.md`)
- [ ] Architecture diagram — `docs/architecture_diagram.png`
      (source: `docs/architecture_diagram.mmd`)
- [ ] 4–8 screenshots with captions — `docs/screenshots/` (10 images + index)
- [ ] Evaluation files — `eval/test_cases.csv`,
      `eval/evaluation_results.csv`, `eval/version_notes.md`,
      `eval/pytest_phase3_run.txt`
- [ ] Failure log — `eval/failure_log.md` (narrative:
      `eval/failure_analysis.md`)
- [ ] AI usage log — `AI_USAGE.md`
- [ ] Final artifact or app — code in `aeromind/`, runnable via README
- [ ] Exported outputs or artifacts — `traces/` + `outputs/sample_runs/`
- [ ] 5-minute video — link in `media/demo_video_link.txt`
- [ ] Working repository or project folder — GitHub link in the PDF packet
- [ ] Individual contribution reflections — one file per member under
      `phase_submissions/phase3/reflections/`
- [ ] Submission packet PDF — `phase_submissions/phase3/submission_packet.pdf`
